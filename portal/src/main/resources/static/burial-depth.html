4 · Field checks before burial

    Reference and limitations

    This planning aid uses the ordinary earth-trench reference values associated with 2024 CEC Rule 12-012 and Table 53, including the high-voltage columns. Ontario adopted the 2024 OESC effective May 1, 2025. The figures are not a final design approval or a substitute for licensed Code material. High-voltage installations also require Section 36 review.

    • Nexans — 2024 CEC changes, Table 53 comparison (page 59)
    • ESA — Ontario Electrical Safety Code
    • Ontario Dig Authority — request utility locates

    Important: The table reference covers minimum burial protection for the selected basic case, not all requirements for cable ratings, duct banks, load capacity, separations, trench stability, restoration or engineered utility design. A proposed cover that meets the reference value is not automatically code-compliant. Excavation must not start before required locates and safe-work arrangements are complete.

    Source basis: CSA C22.1:24, Section 0 voltage definitions; Rule 12-012/Table 53; Sections 36 and 68 as applicable; the actual 2024 Ontario amendments and relevant distributor construction standards.
